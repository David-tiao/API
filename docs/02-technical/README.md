# 02｜专业技术篇

适合已经掌握基本 Web 与编程概念、希望理解代码设计或准备技术答辩的读者。建议按以下顺序阅读：

| 文档 | 核心内容 |
|---|---|
| [01-ARCHITECTURE.md](01-ARCHITECTURE.md) | 详细架构：控制面与数据面、模块依赖、端到端流程、运行状态、安全边界和部署验证 |
| [02-ALGORITHMS.md](02-ALGORITHMS.md) | 数学与算法：有界图遍历、AST/Regex、作用域判定、并发与速率、路径等价类、证据集合、召回/精确率及稳定性；明确公式与真实实现之间的区别 |
| [03-VERSION_HISTORY.md](03-VERSION_HISTORY.md) | V0–V18、PR #1/#2 的简明时间线：每轮改变什么、为什么改变、验证到哪一步 |
