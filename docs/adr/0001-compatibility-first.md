# ADR-0001 保留现有 Python 包入口，先拆分职责

- **状态**：采用，2026-11-22。
- **背景**：已有固定的 Docker CLI、根目录 `api_extractor/`、Node AST 路径及启动脚本；用户希望规范文件结构，但暂不执行真实 Docker 测试。
- **决策**：保留所有运行期关键路径，把旧 ZIP/备份移入 `archive/legacy/`；用 `candidates.py` 将候选映射从主编排抽成纯函数；新增文档与测试索引。
- **原因**：避免破坏 Python import、Docker COPY、Playwright 环境及历史脚本；不为了漂亮的目录树引入重复实现。
- **代价**：提交规范推荐的 `src/` 源码目录尚未实现，评测兼容性需以后单独验证。
- **否决方案**：同时维护根目录与 `src/` 两套代码，易漂移；直接在未验证 Docker 的状态下搬迁整个 Python 包，风险超出本轮收益。
- **本轮依据**：候选映射 8 项离线测试通过；此证据不等于整仓库或 Docker 验收通过。
